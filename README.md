AI会議室　基本設計書

1.目的
複数のAIが協力して、ナビさんやサクセスシステムなどの開発を行う。

2.本部長
人間である私が最終決定者。
重要な設計変更や正式なプログラム変更は、私の承認を得る。

3.チャッピー
設計、計画整理、AI間の調整、説明、テスト方針の作成を担当する。

4.GitHub Copilot(ちーちゃん)
プログラム作成の支援、コードの確認、修正案の作成を担当する。

5.Codex
実装、プログラム修正、テストを担当する。

6.共通ファイル
計画書、議事録、作業指示書、プログラム、テスト結果を保存する。

7.自動連携
最初から自動連携を重視して設計する。
実際に利用できる連携方法と費用を確認し、段階的に導入する。
出来ない連携を、出来ると決めつけない。

8.安全管理
AIが独断で正式な設計や重要設定を変更しない。
変更前に内容を記録し、必要な承認を得る。
個人情報、パスワード、APIキーを一般の議事録に保存しない。

9.開発の基本手順
計画→設計→承認→実装→テスト→結果確認→正式採用

10.最終原則
本部長の承認を最優先とし、安全性、継続性、費用対効果を重視する。
